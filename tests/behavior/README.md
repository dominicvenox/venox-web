# Behavior inputs

These fictional inputs seed independent evaluations described in
[the behavior protocol](../../docs/behavior-tests.md). The audit case intentionally
contains defects; it is not a website example or a recommended implementation.

Copy one scenario into a disposable directory, install or reference the Venox skill,
and give a fresh agent the corresponding request. Keep evaluator output separate
from these baseline files. Paid inference is not run automatically by CI.
